# Changelog

All notable changes to goodvibrations HQ are documented here.

---

## [1.0] — 2026-03-19

### Added
- Folder tree browser mirroring your music folder structure
- Instant project search with live filtering
- Audio playback with play/pause, next/prev track controls
- Keyboard shortcuts: Space (play/pause), ⌘→/⌘← (next/prev), ⌘O (open folder), ⌘R (refresh)
- Smart sorting: recently edited, date added, alphabetical — persisted between sessions
- Finder colour tag display per project
- Reveal in Finder on project hover
- Full state persistence: selected project, expanded folders, sort order all restored on relaunch
- Click `[goodvibrations HQ]` logo to open Settings (also ⌘,)
- Expand all / collapse all folder buttons
- Appearance modes: system, dark, light
- Automatic update notifications via GitHub Releases
- `build-app.sh` script for building a distributable `.app` bundle
- GitHub Actions workflow for automated releases on git tag push
